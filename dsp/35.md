# `0x35` DSP Status

DSP `0x6a` → GT `0x3b`

The DSP uses this command to report the current mode, echo, room and equaliser settings.

### Related Commands

- `0x36` [DSP Control](36.md)
- `0x34` [DSP Equalizer Button](34.md)
- `0x32` [DSP Volume](32.md)

### Example Frames

    6A 0D 3B 35 05 01 23 08 22 42 61 82 A5 C8 A8

## Parameters

Ten data bytes are used.

| Parameter      | Index | Length | Type     |
|:---------------|:------|:-------|:---------|
| **Mode**       | `0`   | `1`    | Bitfield |
| **Room**       | `1`   | `1`    | Bitfield |
| **Echo**       | `2`   | `1`    | Bitfield |
| **EQ Band 1**  | `3`   | `1`    | Bitfield |
| **EQ Band 2**  | `4`   | `1`    | Bitfield |
| **EQ Band 3**  | `5`   | `1`    | Bitfield |
| **EQ Band 4**  | `6`   | `1`    | Bitfield |
| **EQ Band 5**  | `7`   | `1`    | Bitfield |
| **EQ Band 6**  | `8`   | `1`    | Bitfield |
| **EQ Band 7**  | `9`   | `1`    | Bitfield |

### Mode

The low three bits carry the mode. The remaining bits are not defined here.

    MODE    = 0b0000_0111

### Room

The low three bits are used.

    ROOM    = 0b0000_0111

### Echo

The low three bits are used.

    ECHO    = 0b0000_0111

### EQ Bands

Each of the seven EQ bytes contains a band index, sign, and magnitude.

    BAND    = 0b1110_0000
    SIGN    = 0b0001_0000
    VALUE   = 0b0000_1111

#### Band `0b1110_0000`

    BAND_1  = 0b0000_0000
    BAND_2  = 0b0010_0000
    BAND_3  = 0b0100_0000
    BAND_4  = 0b0110_0000
    BAND_5  = 0b1000_0000
    BAND_6  = 0b1010_0000
    BAND_7  = 0b1100_0000

#### Sign `0b0001_0000`

    POSITIVE    = 0b0000_0000
    NEGATIVE    = 0b0001_0000

#### Value `0b0000_1111`

Magnitude. Values above `10` are clamped to `10`.

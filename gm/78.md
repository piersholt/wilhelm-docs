# `0x78` Memory

General Module `0x00` → Global Broadcast `0xbf`\
Seat Memory: Driver `0x72` → Global Broadcast `0xbf`

Used for Key Memory and seat-memory signalling.

### Related Commands

- `0x72` [Remote Key Buttons & Status](72.md)
- `0x74` [Immobiliser Status](../ews/74.md)


## General Module `0x00` → Global Broadcast `0xbf`

The General Module broadcasts this command as part of Key Memory and seat-memory coordination.

The GM identifies the remote key used to lock or unlock the vehicle and coordinates storing or recalling driver-specific settings. Depending on vehicle equipment and coding, Key Memory can include the driver's seat, mirrors and steering column.


### Example Frames

    00 04 BF 78 00 C3
    00 04 BF 78 01 C2
    00 04 BF 78 02 C1
    00 04 BF 78 04 C7
    00 04 BF 78 0A C9

### Parameters

Fixed length. One byte.

Observed values include `0x00`, `0x01`, `0x02`, `0x04` and `0x0a`.

The exact meaning and bit layout of these values is TBC.

## Seat Memory: Driver `0x72` → Global Broadcast `0xbf`

Seat-memory modules also use command `0x78` for memory-position signalling.

A known E46 frame is:

    72 05 BF 78 05 00 B5  # Save memory position 1

This variant uses at least two data bytes. The complete value mapping is TBC.

# `0x7d` Sunroof & Convertible Status

General Module `0x00` → Global Broadcast `0xbf`

Reports sunroof operating permission, convenience opening/closing and convertible-top/roof-lid states.

### Example Frames

    00 05 BF 7D 00 00 C7  # No convenience operation, sunroof not enabled
    00 05 BF 7D 00 10 D7  # Sunroof enabled
    00 05 BF 7D 00 20 E7  # Convenience opening
    00 05 BF 7D 00 60 A7  # Convenience closing
    00 05 BF 7D 00 70 B7  # Convenience closing + sunroof enabled

## Parameters

Fixed length. Two bytes. The following mapping applies to GM5 SW45.

    Byte 0
    CONVERTIBLE_WINDOW_CLOSE = 0b0000_0001

    Byte 1
    ROOF_LID_NOT_LOCKED       = 0b0000_0001
    CONVERTIBLE_CONTACT      = 0b0000_0010
    ROOF_LID_STATE           = 0b0000_0100
    CONVERTIBLE_WINDOW_OPEN  = 0b0000_1000
    SUNROOF_ENABLED          = 0b0001_0000
    CONVENIENCE_OPERATION    = 0b0110_0000

### Sunroof Enabled `0b0001_0000`

Set when the sliding/tilting sunroof is operable. This is an operating permission, not an open-position indication.

### Convenience Operation `0b0110_0000`

| Value | Operation |
|:------|:----------|
| `0x00` | None |
| `0x20` | Opening |
| `0x60` | Closing |

The GM sets bits 5 and 6 together for closing. It does not emit `0x40` alone.

### Convertible Status

Byte 1 bits 0–2 are populated when `FUNKTION_CABRIO` is enabled and `E52_FUNKTIONEN` is disabled. Bit 0 reports that the roof lid is not locked. The exact physical meanings of the contact in bit 1 and the roof-lid state in bit 2 are TBC.

With `VERDECK_VORNE_E85` enabled, byte 0 bit 0 follows the input used for `CVM_FZ` (windows close). Byte 1 bit 3 follows the inverted input used for `CVM_FA` (windows open). The corresponding mechanical top positions are TBC.

Without that option, byte 1 bit 3 is populated through the window-lowering path when `E85_FUNKTIONEN` and `FH_ABSENKEN_VERDECK_OEFF` are enabled.

Byte 0 bits 1–7 and byte 1 bit 7 are not set by the analysed transmitter.

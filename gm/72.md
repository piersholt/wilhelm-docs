# `0x72` Remote Key Buttons

General Module `0x00` → Global Broadcast `0xbf`

Reports remote-control key button activity.

### Related Commands

- `0x72` [FBZV Check Control Status](../fbzv/72.md)
- `0x74` [Immobiliser Status](../ews/74.md)
- `0x76` [Exterior Light Flashing](76.md)
- `0x78` [Memory](78.md)

### Example Frames

    00 04 BF 72 00 C9  # No button
    00 04 BF 72 02 CB  # No button, different key identification
    00 04 BF 72 10 D9  # Lock
    00 04 BF 72 12 DB  # Lock, key identification 1
    00 04 BF 72 13 DA  # Lock, key identification 1, key battery low
    00 04 BF 72 20 E9  # Unlock
    00 04 BF 72 22 EB  # Unlock, key identification 1
    00 04 BF 72 23 EA  # Unlock, key identification 1, key battery low
    00 04 BF 72 42 8B  # Boot

## Parameters

Fixed length. One byte.

    BUTTON              = 0b1111_0000
    KEY_IDENTIFICATION  = 0b0000_1110
    KEY_BATTERY_LOW     = 0b0000_0001

### Button `0b1111_0000`

    NO_BUTTON = 0x00
    LOCK      = 0x10
    UNLOCK    = 0x20
    BOOT      = 0x40

### Key Identification `0b0000_1110`

Identifies the initialised FZV remote key.

The FZV identifier is independent from the EWS key identifier.

The field is shifted left by one bit. Remote Key 1 is observed as `0x02`; `0x06` therefore identifies Remote Key 3. `0x00` is also observed when no button is active.

### Key Battery Low `0b0000_0001`

Set when the remote key reports a low battery.

For example, Remote Key 1 changes from `0x12` to `0x13` for the lock-button report when this bit is set.

## Use Cases

### Central Locking

The GM broadcasts the remote button operation after receiving and validating an FZV key signal.

### Key Memory

The remote-key identification allows Key Memory settings to be associated with the key used to lock or unlock the vehicle.

# `0x71` Remote Key Status Request

Any device → General Module `0x00`

Requests remote-control key button status. The GM responds with `0x72` to Global Broadcast `0xbf`.

### Related Commands

- `0x72` [Remote Key Buttons & Status](72.md)

### Example Frames

    5B 03 00 71 29

## Parameters

No data bytes.

## Use Cases

### Remote Key Status

Requests the remote key button, key identification and low-battery status reported by the GM through `0x72`.

### Car/Key Memory

IHKA can use this request to obtain the remote-key identification through `0x72` and select the corresponding Car/Key Memory (CKM) settings.

# `0x7a` Door/Lid Status

General Module `0x00` → Global Broadcast `0xbf`

Broadcasts door, lid, window, sunroof, central-locking and interior-light status.

Driver/passenger naming is intentional: the rear-door and rear-window bits follow driver/passenger side rather than fixed left/right positions, so the same mapping applies to LHD and RHD vehicles.

### Related Commands

- `0x79` [Door/Lid Status Request](79.md)
- `0x72` [Remote Key Buttons](72.md)
- `0x7c` [Sunroof Status](../shd/7c.md)
- `0x7d` [Sunroof Control](../shd/7d.md)

### Example Frames

    00 05 BF 7A 51 1F 8E  # Driver front door; all windows and sunroof open; interior light on
    00 05 BF 7A 54 00 94  # Driver rear door open; interior light on
    00 05 BF 7A 58 00 98  # Passenger rear door open; interior light on
    00 05 BF 7A 53 40 D3  # Front doors and bonnet open; interior light on
    00 05 BF 7A 10 20 F0  # Rear lid open; vehicle unlocked
    00 05 BF 7A 90 20 70  # Rear-lid release active; rear lid open; vehicle unlocked

## Parameters

Fixed length. Two-byte bitfield.

    # Byte 1
    DOORS             = 0b0000_1111 << 8
    CENTRAL_LOCKING   = 0b0011_0000 << 8
    LAMP_INTERIOR     = 0b0100_0000 << 8
    REAR_LID_RELEASE  = 0b1000_0000 << 8

    # Byte 2
    WINDOWS           = 0b0000_1111
    SUNROOF           = 0b0001_0000
    REAR_LID          = 0b0010_0000
    FRONT_LID         = 0b0100_0000
    REAR_LID_INTERIOR_RELEASE = 0b1000_0000

---

### Doors `0b0000_1111 << 8`

    DOOR_DRIVER_FRONT      = 0b0000_0001     # Driver front door open
    DOOR_PASSENGER_FRONT   = 0b0000_0010     # Passenger front door open
    DOOR_DRIVER_REAR       = 0b0000_0100     # Driver-side rear door open
    DOOR_PASSENGER_REAR    = 0b0000_1000     # Passenger-side rear door open

The rear bits are side-relative. For example, `0x04` is the rear door on the driver's side on both LHD and RHD vehicles.

### Central Locking `0b0011_0000 << 8`

State of the central locking system.

    CENTRAL_LOCKING_UNLOCKED    = 0b0001_0000   # Unlocked
    CENTRAL_LOCKING_LOCKED      = 0b0010_0000   # Locked (single lock)
    CENTRAL_LOCKING_ARRESTED    = 0b0011_0000   # Arrested (double lock)

The interior-light bit may be combined with these values. For example, `0x50` is unlocked with the interior light on, while `0x70` is double locked with the interior light on.

### Lamp Interior `0b0100_0000 << 8`

Set while the GM reports the interior lighting active.

    LAMP_INTERIOR     = 0b0100_0000

### Rear-Lid Release `0b1000_0000 << 8`

A short-lived release indication associated with opening the luggage compartment.

    REAR_LID_RELEASE  = 0b1000_0000

An observed release sequence is:

    00 05 BF 7A 90 20 70
    00 05 BF 7A 10 20 F0

The first frame adds bit 7 while the rear-lid-open bit is set; the following frame clears the release indication again.

---

### Windows `0b0000_1111`

    WINDOW_DRIVER_FRONT      = 0b0000_0001     # Driver front window open
    WINDOW_PASSENGER_FRONT   = 0b0000_0010     # Passenger front window open
    WINDOW_DRIVER_REAR       = 0b0000_0100     # Driver-side rear window open
    WINDOW_PASSENGER_REAR    = 0b0000_1000     # Passenger-side rear window open

The rear-window bits are side-relative, matching the door-field convention.

The window position is based on the respective regulator motor position/end-limit state. After loss of initialisation, a window may be reported as open until its position has been re-established.

### Sunroof `0b0001_0000`

    SUNROOF     = 0b0001_0000   # Sunroof open

The sunroof position is derived from the SHD/motor position state.

### Rear Lid `0b0010_0000`

    REAR_LID    = 0b0010_0000   # Luggage compartment/rear lid open

On Touring models, the rear lid and rear-window/hatch contacts may both contribute to the luggage-compartment-open state.

### Front Lid `0b0100_0000`

    FRONT_LID   = 0b0100_0000   # Front lid (hood/bonnet) open

The bonnet contact is also used by the integrated DWA system.

### Interior Rear-Lid Release `0b1000_0000`

Set from the GM input `TOEHKI`:

    Taster zum Oeffnen der Heckklappe von Innen

This is distinct from byte 1 bit 7, which is the short-lived rear-lid release state used by the normal luggage-compartment opening sequence.

## Use Cases

### Check Control

Several Check Control messages depend on ZKE door/lid state, including door-open and luggage-compartment-open warnings.

The LCM uses the door field, central-locking field, rear-lid bit and front-lid bit from this message for its own Check Control/lighting logic.

### Electronic Drive Away Protection (EWS)

The GM communicates the central-locking state on the vehicle bus. EWS III uses lock/double-lock information as part of vehicle immobilisation coordination.

### Body/Display Status

CCM, IKE and BMBT have all been observed requesting the current state with `0x79`; the GM answers with this broadcast.

# `0x77` Wiper Status

General Module `0x00` → RLS `0xe8`

Reports the current wiper-stalk, intermittent-wiper potentiometer and washer-sequence state to the Rain/Light Sensor.

### Related Commands

- `0x58` [RLS Wiper Interval Data](../rls/58.md)
- `0x75` [Wiper Status Request](75.md)

### Example Frames

    00 04 E8 77 04 9F  # Potentiometer selector 1, wiper stalk off
    00 04 E8 77 05 9E  # Potentiometer selector 1, intermittent
    00 04 E8 77 0C 97  # Potentiometer selector 3, wiper stalk off
    00 04 E8 77 0D 96  # Potentiometer selector 3, intermittent
    00 04 E8 77 0E 95  # Potentiometer selector 3, wiper stage 1

## Parameters

Fixed length. One-byte bitfield.

    WIPER_STALK              = 0b0000_0011
    POTENTIOMETER_SELECTOR   = 0b0000_1100
    POTENTIOMETER_INVALID    = 0b0001_0000
    WASH_SEQUENCE_ACTIVE     = 0b0010_0000
    INTENSIVE_WASH_ACTIVE    = 0b0100_0000

### Wiper Stalk `0b0000_0011`

The two low bits come directly from the GM's `SW1` and `SW2` wiper-stalk inputs:

    0b00  OFF
    0b01  INT
    0b10  STAGE_1
    0b11  STAGE_2

The underlying GM inputs are `SW1` (INT / encoded ST2) and `SW2` (ST1 / encoded ST2).

There is no wiper-park-contact bit in this message.

### Potentiometer Selector `0b0000_1100`

The GM converts the intermittent-wiper potentiometer input into four valid ascending analog bands:

    selector 0  -> 0x00
    selector 1  -> 0x04
    selector 2  -> 0x08
    selector 3  -> 0x0C

The corresponding raw ADC ranges are:

    0x09..0x65  -> 0x00
    0x66..0x8D  -> 0x04
    0x8E..0xA9  -> 0x08
    0xAA..0xF9  -> 0x0C

The selector is derived from the wiper-potentiometer voltage (`UWIINT`).

### Potentiometer Invalid `0b0001_0000`

Set when the potentiometer signal is outside the valid range.

The GM distinguishes the two ends on the wire:

    raw < 0x09   -> 0x10
    raw > 0xF9   -> 0x14

Thus bit 4 is an out-of-range qualifier rather than another normal sensitivity position.

### Wash Sequence Active `0b0010_0000`

Set while the processed normal washer/wipe sequence is active, including its timed follow-up state.

The source sequence is initiated by the `SWP` washer-pump switch input, but this bit is a GM state-machine status rather than the raw switch level.

### Intensive Wash Active `0b0100_0000`

Set while the processed intensive-wash sequence is active.

The source sequence is initiated by the `SIR` intensive-washer switch input. As with bit 5, the transmitted bit represents the active GM sequence rather than the raw button level.

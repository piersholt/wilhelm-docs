# `0x79` Door/Lid Status Request

Various → General Module `0x00`

Requests the General Module's door/lid status. The GM responds by broadcasting `0x7a`.

### Related Commands

- `0x7a` [Door/Lid Status](7a.md)

### Example Frames

    30 03 00 79 4A  # CCM → GM
    80 03 00 79 FA  # IKE → GM
    F0 03 00 79 8A  # BMBT → GM

## Parameters

Fixed length. No parameters.

## Use Cases

The request is used by multiple body/display modules when they need the current door, lid, window and central-locking state.

The BMBT has also been observed polling this status during wake/start-up sequences.

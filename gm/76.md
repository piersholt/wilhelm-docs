# `0x76` Visual Indicators

General Module `0x00` → Global Broadcast `0xbf`

Controls visual indications through the exterior lamps and also carries the crash/alarm state used with those indications.

The LCM performs the lamp output. The GM uses this command for central-locking acknowledgements, DWA optical alarm signalling and the crash state.

### Example Frames

    00 04 BF 76 00 CD  # Stop indication
    00 04 BF 76 02 CF  # Warning lights
    00 04 BF 76 04 C9  # Low beams
    00 04 BF 76 08 C5  # High beams
    00 04 BF 76 0E C3  # Warning lights + low beams + high beams
    00 04 BF 76 82 4F  # DWA optical alarm active + warning lights

## Parameters

Fixed length. One-byte bitfield.

    CRASH_STATE       = 0b0100_0001
    WARNING_LIGHTS    = 0b0000_0010
    LOW_BEAMS         = 0b0000_0100
    HIGH_BEAMS        = 0b0000_1000
    DWA_ALARM_ACTIVE  = 0b1000_0000

### Crash State `0b0100_0001`

The GM emits bits 0 and 6 together as one crash-state encoding. They are not independent fields in this protocol form.

When the GM's processed crash state becomes active, `0x41` is ORed into the outgoing value.

### Warning Lights `0b0000_0010`

Flashes the exterior turn signal lamps together.

This doesn't activate the turn signal indicators in the instrument cluster or the normal hazard-warning switch indication.

The bit is used both for normal visual locking acknowledgement and, when configured, as one of the DWA optical-alarm outputs.

### Low Beams `0b0000_0100`

Flashes the low beams when selected for DWA optical alarm indication.

### High Beams `0b0000_1000`

Flashes the high beams when selected for DWA optical alarm indication.

### DWA Alarm Active `0b1000_0000`

Set by the GM while the DWA optical-alarm path is active.

The selected optical outputs are added according to GM coding:

    COD_OPT_ALARM_WARNBL  -> WARNING_LIGHTS
    COD_OPT_ALARM_ABBLLI  -> LOW_BEAMS
    COD_OPT_ALARM_FERNLI  -> HIGH_BEAMS

For example, `0x82` means DWA optical alarm active with warning-light output selected. LCM uses the lamp-selection bits for its physical outputs and does not need bit 7 to select the lamps.

### Stop `0x00`

Stops an active visual indication when no crash or alarm state is present.

## Use Cases

### Central Locking

Visual lock and unlock acknowledgements use the warning-light bit. The GM sends the indication and later clears it again.

    00 04 BF 76 02 CF
    00 04 BF 76 00 CD

The acknowledgement behaviour is controlled by GM coding including `COD_QS_WARNBL` and `COD_QE_WARNBL`.

### Anti-Theft (DWA)

The DWA function is integrated in the GM. During an optical alarm the GM sets `DWA_ALARM_ACTIVE` and adds the configured exterior lamp groups.

### Crash

The processed GM crash state adds the composite value `0x41`. This encoding is separate from the DWA alarm qualifier and can coexist with the lamp-selection bits.

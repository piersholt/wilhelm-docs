# `0x18` Speed / RPM

Cluster `0x80` → Global Broadcast `0xbf`

The cluster periodically broadcasts vehicle speed and engine speed.\
There is no separate request command for this data.\
The cluster increases the update speed when the vehicle starts moving.

### Related

- `0x13` [Sensors](13.md)

### Example Frames

    80 05 BF 18 41 19 7A   # 130 km/h, 2500 rpm
    80 05 BF 18 42 19 79   # 132 km/h, 2500 rpm

## Parameters

Fixed length. 2 data bytes.

| Parameter | Index | Length | Type    | Resolution |
|:----------|:------|:-------|:--------|:-----------|
| Speed     | `0`   | `1`    | Integer | 2 km/h     |
| RPM       | `1`   | `1`    | Integer | 100 rpm    |

A speed value of `0xff` indicates an invalid value.

### Speed

    speed_kmh = byte_0 * 2

### RPM

    rpm = byte_1 * 100

## Usage

### LCM

#### Vehicle Speed

A number of lamp-monitoring and Check Control paths distinguish stationary from moving simply by testing the raw Speed byte for zero. While moving, the LCM enables or accumulates several lamp/fault states that are suppressed or reset while stationary.

The speed value is also used by the Brake Force Display logic. The BFD minimum-speed qualifier uses a coding-derived threshold. Once the minimum-speed state is active, it is cleared only after the raw speed falls two counts below the activation threshold. Since one raw count is `2 km/h`, this gives the BFD speed qualifier an explicit `4 km/h` hysteresis.

#### Engine RPM

When the LCM is configured to evaluate the local oil-level sensor, it periodically accumulates and averages the raw RPM value together with the local oil-sensor measurement. The resulting operating-point correction is used by the oil-level state machine that produces the local oil-level and oil-level-sensor warning states.

# `0x19` Temperature

Cluster `0x80` → Global Broadcast `0xbf`

The cluster periodically broadcasts ambient and coolant temperature.

Temperature values use Celsius (℃) on the bus.\
The unit selected with `0x15` [Language & Region](15.md) does not change this command.

### Related Commands

- `0x1d` [Temperature Request](1d.md)
- `0x13` [Sensors](13.md)

### Example Frames

    80 06 BF 19 0F 54 00 7B
    80 06 BF 19 0A E2 00 C8
    80 06 BF 19 17 37 00 00

## Parameters

Fixed length. 3 data bytes.

| Parameter | Index | Length | Type | Note |
|:----------|:------|:-------|:-----|:-----|
| Ambient | `0` | `1` | Integer (signed) | ℃ |
| Coolant | `1` | `1` | Integer (signed) / escape | ℃ |
| Coolant Extension | `2` | `1` | Integer / status | Normally `0x00`; used when Coolant is `0x7f` |

### Ambient

The ambient value is a signed one-byte Celsius value.\
The cluster receives the measurement from the external temperature sensor.

### Coolant

The primary coolant byte is a signed Celsius value, with `0x7f` reserved as an escape.\
Ordinary values below `0x7f` therefore represent temperatures directly; for example `0xe2` corresponds to `-30℃`, not `226℃`.

### Coolant Extension

    if coolant == 0x7f:
        if extension & 0x80:
            effective_coolant = 0xff
        else:
            effective_coolant = 0x7f + extension

Extension values `0x00..0x7f` extend the effective coolant value from `127℃` through `254℃`. \
For normal coolant temperatures the third byte is normally `0x00` and has no effect.

## Use Cases

### Check Control

The LCM uses the ambient temperature and, depending on coding, for the numeric coolant-overtemperature warning.

The coolant warning can alternatively be sourced from the extended `0x13` coolant-overtemperature status.

The LCM uses the coolant value for the coolant-overtemperature Check Control path when the corresponding CAN-overtemperature coding path is disabled. The warning threshold is coding-dependent. Once active, the numeric warning is cleared only after the effective temperature falls at least `5℃` below the configured threshold, giving this path an explicit `5℃` hysteresis.

When the CAN-overtemperature coding path is enabled, the LCM does not use the numeric coolant value for this warning. It instead uses the `COOLANT_TEMPERATURE` status supplied in the extended `0x13` [Sensors](13.md) frame.

# `0x06` Video Module Service Mode Reply

VID `0xed` → GT `0x3b`

GT uses this reply for the Video Module version shown in service mode.

### Related Commands

- `0x06` [BMBT Service Mode Reply](../bmbt/06.md)

## Parameters

At least 12 data bytes.

The identification layout matches the version data used by the BMBT service mode reply.

| Property              | Index | Length | Type |
|:----------------------|:------|:-------|:-----|
| *BMW Part Number*     | `0`   | `4`    | BCD  |
| **HW level**          | `4`   | `1`    | BCD  |
| **Encoding index**    | `5`   | `1`    | BCD  |
| **DIAG index**        | `6`   | `1`    | BCD  |
| **BUS index**         | `7`   | `1`    | BCD  |
| *Date of Manufacture* | `8`   | `2`    | BCD  |
| **Supplier**          | `10`  | `1`    | BCD  |
| **SW Level**          | `11`  | `1`    | BCD  |

HW level, Encoding index, DIAG index, BUS index, Supplier and SW Level are used for the service display. Part number and date are not used there.

# `0x4d` Video Module State

VID `0xed` → GT `0x3b`

The Video Module uses this to update the GT TV state.

### Example Frames

    ED 05 3B 4D 00 00 9E
    ED 05 3B 4D 04 00 9A

## Parameters

Fixed length. Two data bytes.

The first byte is an enumerated TV state. The second byte is zero for the defined states.

| State | Value |
|:------|:------|
| TV state 0 | `00 00` |
| TV state 4 | `04 00` |

These values select two distinct GT TV-state transitions. Other values are ignored by this GT path. The meaning of those values are currently unknown.

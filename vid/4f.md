# `0x4f` Video Module Source

GT `0x3b` → TV / VID `0xbb`

This command controls the source of the video module.\
The GT uses this to switch to TV mode.

### Related Commands

- `0x4d` [Video Module State](4d.md)
- `0x4f` [Monitor Control](../bmbt/4f.md)

### Example Frames

    3B 05 BB 4F 02 00 C8  # GT
    3B 05 BB 4F 01 00 CB  # TV
    3B 05 BB 4F 09 00 C3  # Unknwon

## Parameters

Two byte bitfield, although the second byte can be negated.

    # Byte 1
    SOURCE       = 0b0000_0011

    # Byte 2 (Optional)
    ENCODING     = 0b0000_0011
    ASPECT_RATIO = 0b0011_0000

### Source `0b0000_0011 << 8`

    SOURCE_NAV_GT = 0b0000_0000
    SOURCE_TV     = 0b0000_0001
    SOURCE_VID_GT = 0b0000_0010

The video module will send a `0x4f`command to the BMBT containing the source.\
Of course the BMBT cannot switch inputs, but it saves a brightness setting for each input.

### Encoding `0b0000_0011 << 0`

    ENCODING_NTSC = 0b0000_0001
    ENCODING_PAL  = 0b0000_0010

### Aspect Radio `0b0011_0000 << 0`

    ASPECT_4_3    = 0b0000_0000
    ASPECT_16_9   = 0b0001_0000
    ASPECT_ZOOM   = 0b0011_0000

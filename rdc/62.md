# `0x62` RDC Status

RDC `0x70` → Broadcast `0xbf`

Reports tire-pressure-control status used by Check Control.

### Related Commands

- `0x1a` [Check Control Message](../lcm/1a.md)
- `0x52` [Check Control Message Relay](../lcm/52.md)

### Example Frames

    70 05 BF 62 00 00 A8
    70 05 BF 62 00 01 A9

## Parameters

Two data bytes.

    Byte 1
    UNKNOWN

    Byte 2
    RDC_INACTIVE = 0b0000_0010

### RDC Inactive `0b0000_0010`

When set, the LCM reports a defective tire pressure monitoring system.

RDC can also relay full Check Control text through `0x52`.

# `0xa9` BMW Assist Data

Telephone `0xc8` → Navigation `0x7f`  
Navigation `0x7f` → Telephone `0xc8`

Carries BMW Assist and telephone records between the navigation computer and telephone. The first data byte selects the record type.

### Related Commands

- `0xa2` [Telematics Coordinates](a2.md)
- `0xa4` [Telematics Location](a4.md)

### Example Frames

    7F 06 C8 A9 0A 30 30 12                # Current phone status request, count 0
    C8 07 7F A9 0B 00 00 04 16             # Current phone status response
    7F 06 C8 A9 03 30 30 1B                # Current network request, count 0
    C8 0B 7F A9 04 00 00 00 00 00 00 00 11 # Current network response

## Parameters

Length depends on the record type.

| Property | Index | Length | Type |
|:---------|:------|:-------|:-----|
| Type     | `0`   | `1`    | Byte |
| Data     | `1`   | varies | Data |

## Navigation → Telephone

### Current Network Request `0x03`

Observed requests use two ASCII count bytes after the type.

    03 30 30    # Count 0

The corresponding Telephone response uses type `0x04`.

### Current Phone Status Request `0x0a`

Observed requests use two ASCII count bytes after the type.

    0A 30 30    # Count 0

The corresponding Telephone response uses type `0x0b`.

## Telephone → Navigation

Known Telephone records include:

| Type | Data |
|:-----|:-----|
| `0x02` | Two control bytes followed by up to 32 characters |
| `0x04` | Current network response; two control bytes followed by up to 10 characters |
| `0x0b` | Current phone status response |
| `0x18` | Two control bytes followed by up to 32 characters |
| `0x19` | Two control bytes followed by up to 32 characters |
| `0x1d` | Two control bytes followed by up to 10 characters |
| `0x31` | Control/status notification |

For `0x0b`, the two status values are carried in data bytes 2 and 3 of the full `0xa9` payload.

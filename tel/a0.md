# `0xa0` Telephone Data

Telephone `0xc8` → GT `0x3b`

The Telephone variant uses record type `0x02` followed by a short text value.

This is the TEL `0xc8` protocol variant. It is unrelated to the TCU `0xca` use of command `0xa0`.

### Related

- `0xa9` [BMW Assist Data](a9.md)

## Parameters

| Property | Index | Length | Type   |
|:---------|:------|:-------|:-------|
| Type     | `0`   | `1`    | Byte   |
| String   | `1`   | `0-10` | String |

### Type

    DATA = 0x02

### String

Up to ten bytes are used.

# `0xa5` Body Text

Writes indexed body text and allows an offset within a field so a long line can be sent in multiple messages.

### Variants

- [Radio](../rad/a5.md)
- [Telephone](../tel/a5.md)

## Parameters

Length will vary with *String*.

| Property | Index | Length | Type     |
|:---------|:------|:-------|:---------|
| Layout   | `0`   | `1`    | Bitfield |
| Offset   | `1`   | `1`    | Bitfield |
| Options  | `2`   | `1`    | Bitfield |
| String   | `3`   | `-1`   | String   |

### Offset

The 5 LSBs represent the character offset.

    0b0000_0001   # 0 chars offset
    0b0000_0010   # 1 char offset
    0b0000_0011   # 2 chars offset
                  # [...]
    0b0001_1111   # 30 chars offset

An offset of zero characters is represented by `0x01`, not `0x00`.

### Options

    INDEX       = 0b0001_1111
    CLEAR       = 0b0010_0000
    BUFFER      = 0b0100_0000
    BLINK       = 0b1000_0000

#### Index `0b0001_1111`

Each layout has a given number of fields, each represented by an index.

The control character `0x06` advances to the next field.

#### Clear `0b0010_0000`

Clears the given layout, including its buffer.

#### Buffer `0b0100_0000`

Preliminary writes may be buffered while a display is populated. Clearing this bit on the final write renders the completed buffer and returns `0x22` [Text Display Confirmation](22.md).

#### Blink `0b1000_0000`

Lets the text blink. Support for this was removed in the NG-UI.


### String

| Code Point | Name | Description            |
|:-----------|:-----|:-----------------------|
| `0x00`     | NUL  | Null-terminated string |
| `0x06`     | LF   | Next field             |

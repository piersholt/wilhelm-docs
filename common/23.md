# `0x23` Title Text

Writes title or status text. Layout values and string controls depend on the sender and display.

### Variants

- [Radio](../rad/23.md)
- [Telephone](../tel/23.md)
- [TCU](../tcu/23.md)

## Parameters

The common display form is:

| Property | Index | Length | Type     |
|:---------|:------|:-------|:---------|
| Layout   | `0`   | `1`    | Bitfield |
| Options  | `1`   | `1`    | Bitfield |
| String   | `2`   | `-1`   | String   |

The meaning of `Layout` is sender-specific.

### Options

Common GT title-text options include:

    UPDATE  = 0x20
    SET     = 0x30

### String

`0x00` terminates a string. Additional control codes are defined by the applicable sender/display variant.

Radio title strings may also define property and discard substrings; see [Title Text: Radio](../rad/23.md).

# `0x01` "Ping"

Requests a presence reply from another module.

The command has no payload.\
The addressed module normally answers with command `0x02` using the pong form of its normal announcement signature.

### Related Commands

- [`0x02` "Pong" / Announce](02.md)

### Example Frames

    50 03 C8 01 9A       # MFL pings Telephone
    C8 04 50 02 30 AE    # Telephone replies with 0x02

    3B 03 ED 01 D4       # GT pings TV
    ED 04 3B 02 00 D0    # TV replies with 0x02

# `0x24` Property Text

Updates a short display property without rewriting the complete title or screen.

### Variants

- [Radio](../rad/24.md)
- [Telephone](../tel/24.md)
- [IKE / OBC](../ike/24.md)

## Parameters

Length will vary with *String*.

| Property | Index | Length | Type     |
|:---------|:------|:-------|:---------|
| Layout / Property | `0`   | `1`    | Bitfield |
| Options  | `1`   | `1`    | Bitfield |
| String   | `2`   | `-1`   | String   |

Layout and property values are sender-specific. `Options` is commonly `0x00`.

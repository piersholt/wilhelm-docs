# `0x22` Text Display Confirmation

GT `0x3b` → Radio `0x68`  
GT `0x3b` → Cluster `0x80`  
GT `0x3b` → Telephone `0xc8`

Completes a buffered sequence of `0x21` [Menu Text](21.md) writes.

A write with the `BUFFER` flag set increments the pending write count.\
The first following write with `BUFFER` clear completes the buffer, sends `0x22`, and resets the count.

### Related

- `0x21` [Menu Text](21.md)

## Parameters

Fixed length. 2 data bytes.

### Radio / Cluster

| Property       | Index | Length | Type    |
|:---------------|:------|:-------|:--------|
| Buffered Writes | `0`   | `1`    | Integer |
| Void            | `1`   | `1`    | Byte    |

    VOID = 0xff

### Telephone

| Property        | Index | Length | Type    |
|:----------------|:------|:-------|:--------|
| Void            | `0`   | `1`    | Byte    |
| Buffered Writes | `1`   | `1`    | Integer |

    VOID = 0x00

### Buffered Writes

The count contains the number of preceding `0x21` writes received with `BUFFER` set. The final unbuffered write is not included in this value.

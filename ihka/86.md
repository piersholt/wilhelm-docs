# `0x86` Rear Defroster Status

IHKA `0x5b` → Navigation `0x7f`.

Reports the rear defroster status.\
This is only used by the MK1 so that it can compensate for the magnetic influence from the rear defroster.

### Related Commands

- `0x87` [Rear Defroster Status Request](87.md)

## Examples

    5B 04 7F 86 00 A6    # Defroster off
    5B 04 7F 86 01 A7    # Defroster on

## Properties
Fixed length. One byte bit field.

    # Byte 1
    REAR_DEFROSTER = 0b0000_0001

## Use Cases

### MK1 Compass Compensation

The rear defroster can affect the magnetic field sensor used by MK1 navigation.\
BMW documents a calibrated correction based on the defroster operating state.\
The documented signal path is:

    IHKA → K-Bus → IKE → I-Bus → Video Module → ARCNET → Navigation Computer

On MK1, the MMI runs in the video module and forwards this status to the separate navigation computer.

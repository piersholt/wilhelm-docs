# `0x83` IHKA A/C Control

IHKA `0x5b` → IKE `0x80`

Carries the air-conditioning compressor request and the associated compressor-load and auxiliary-fan request information to the instrument cluster.

### Example Frames

    5B 05 80 83 00 00 5D
    5B 05 80 83 80 08 D5
    5B 05 80 83 D1 40 CC
    5B 05 80 83 D8 A0 25

### Related Commands

- `0x82` [IHKA Status](82.md)

## Parameters

Fixed length. Two data bytes.

| Parameter   | Index | Length | Type     |
|:------------|:------|:-------|:---------|
| **Control** | `0`   | `1`    | Bitfield |
| **Request** | `1`   | `1`    | Integer  |

### Control

    AC_REQUEST = 0b1000_0000

#### A/C Request `0b1000_0000`

Requests air-conditioning compressor activation.

The remaining control bits and the second byte carry compressor-load and requested auxiliary-fan information. The exact layout is not confirmed yet.

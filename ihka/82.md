# `0x82` IHKA Status

IHKA `0x5b` → Graphics Stage `0x3b`.

Reports an IHKA status used by the heating menu.

## Examples

    5B 04 3B 82 00 E6    # Allow aux. heating
    5B 04 3B 82 80 66    # Inhibit aux. heating

## Properties

Fixed length. One byte bit field.

    # Byte 1
    INHIBIT_AUX_HEAT = 0b1000_0000

### Inhibit Aux. Heating `0b1000_0000`

The aux. heat/vent menu uses this to check if the heater can be activated.\
It also checks the ignition status, coding, etc.

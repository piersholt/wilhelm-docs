# `0x87` Rear Defroster Status Request

Navigation `0x7f` → IHKA `0x5b`.

Requests the rear defroster status.\
This is only used by the MK1 so that it can compensate for the magnetic influence from the rear defroster.

### Related Commands

- `0x86` [Rear Defroster Status](86.md)

## Examples

    7F 03 5B 87 A0

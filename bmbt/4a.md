# `0x4a` BMBT Tape/LED Control

Radio `0x68` → BMBT `0xf0`
GT `0x3b` → BMBT `0xf0`

This command is used to control the radio indicator and tape drive.\
Most values are sent by the radio, but GT also uses `0x90` while initialising the BMBT.

### Related Commands

- `0x4b` [BMBT Tape Status](4b.md)

### Example Frames
    68 04 F0 4A 00 D6   # LED Off
    68 04 F0 4A FF 29   # LED On

    68 04 F0 4A 40 96   # Eject Tape

    68 04 F0 4A 4A 9C   # Tape Stop
    68 04 F0 4A 4B 9D   # Tape Play

For detailed examples, see below!

## Parameters

The argument is a control byte. The values are enumerated commands, not bitfields.

`0x00` and `0xff` are also used as the radio power state by display consumers.

### LED Off (0x00)
Turns the radio indicator off. 

    68 04 F0 4A 00 D6

### LED On (0xFF)
Turns the radio indicator on, duh. 

    68 04 F0 4A FF 29

### Eject Tape (0x40)
Flips down the screen and ejects the tape.

    68 04 F0 4A 40 96

### Dolby Mode B (0x5D)
Turns on Dolby B noise reduction.

    68 04 F0 4A 5D 8B

### Dolby Mode C (0x5E)
Turns on Dolby C noise reduction.

    68 04 F0 4A 5E 88

### Dolby Mode Off (0x5F)
Turns off Dolby noise reduction.

    68 04 F0 4A 5F 89

### Tape Side 1 (0x5A)
Switches to tape side 1.\
You have to send a second command (0x41) to actually execute the action.

    68 04 F0 4A 5A 8C
    68 04 F0 4A 41 97  # Execute

### Tape Side 2 (0x5B)
Switches to tape side 2.\
You have to send a second command (0x41) to actually execute the action.

    68 04 F0 4A 5B 8D
    68 04 F0 4A 41 97  # Execute

### Forward (0x44)
Forwards the tape. Can be canceled with the 0x41 command.
    
    68 04 F0 4A 44 92
    68 04 F0 4A 41 97  # Cancel

### Rewind (0x45)
Rewinds the tape. Can be canceled with the 0x41 command.
    
    68 04 F0 4A 45 93
    68 04 F0 4A 41 97  # Cancel

### Fast Forward (0x42)
Fast forwards the tape. Can be canceled with the 0x41 command.
    
    68 04 F0 4A 42 94
    68 04 F0 4A 41 97  # Cancel

### Fast Rewind (0x43)
Fast rewinds the tape. Can be canceled with the 0x41 command.
    
    68 04 F0 4A 43 95
    68 04 F0 4A 41 97  # Cancel

### Play (0x4B)
Starts to play the tape.

    68 04 F0 4A 4B 9D

### Stop (0x4A)
Stops the tape.
    
    68 04 F0 4A 4A 9C

### Current Status / Mode Change (0x48)
Requests/updates the current cassette state.\
The radio sends this together with `0x4a` when switching to another mode.\
If you just turn off the radio, only 0x4A will be sent.
    
    68 04 F0 4A 48 9E

### Execute/Cancel (0x41)
Cancels rewind and forward, commits a pending tape-side change and starts playback if the tape is currently stopped.

    68 04 F0 4A 41 97

### Cassette Insertion Handshake (0x80)
Used during cassette insertion. When the BMBT has reported status `0x80` and cassette presence later changes from `0x05` (no tape) to `0x06` (tape in), the radio sends `0x80` back to the BMBT.

    68 04 F0 4A 80 56

### Reset/Initialise (0x90)
Resets the BMBT rad/tape control state during startup. The normal radio state is applied afterwards, commonly with `0xff` to turn the radio indicator on.

Both the radio and GT use this value during BMBT initialisation.

    68 04 F0 4A 90 46

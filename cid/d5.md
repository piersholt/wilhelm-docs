# `0xd5` CID Display Status

CID `0x46` → Broadcast `0xff`

The flip-up CID uses this command to report the display position.

### Example Frames

    46 05 FF D5 01 00 68   # Open
    46 05 FF D5 01 01 69   # Closed

## Parameters

Fixed length. Two data bytes.

| Parameter | Index | Length | Type |
|:----------|:------|:-------|:-----|
| Type      | `0`   | `1`    | Byte |
| State     | `1`   | `1`    | Map  |

### Type

Type `0x01` is defined here.

    POSITION = 0x01

### State

    OPEN     = 0x00
    CLOSED   = 0x01

## Use Cases

### Flip-up Display

The CID broadcasts `OPEN` after the display has been opened and `CLOSED` after it has been closed.

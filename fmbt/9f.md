# `0x9f` FMBT Rear Monitor Status

FMBT `0x47` → GT `0x3b`

Reports the rear monitor on/off state.

### Related Commands

- `0x9e` [FMBT Rear Monitor Control](9e.md)
- `0xab` [GTF Remote Control Status](../nav/ab.md)

### Example Frames

    47 04 3B 9F 00 E7  # Monitor off
    47 04 3B 9F 01 E6  # Monitor on

## Parameters

At least one data byte is required. Bit 0 of the first byte carries the monitor state.

    MONITOR_ON = 0b0000_0001

### Monitor On `0b0000_0001`

    OFF = 0
    ON  = 1

The status value is inverted compared to the request value sent using `0x9e`:

    9E 00 -> 9F 01
    9E 01 -> 9F 00

Additional data bytes are not defined.

## Use Cases

The GT accepts the returned state when it matches the state requested using `0x9e`. A mismatching state is not applied.

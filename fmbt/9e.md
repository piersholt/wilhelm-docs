# `0x9e` FMBT Rear Monitor Control

GT `0x3b` → FMBT `0x47`

Switches the rear monitor on or off.

### Related Commands

- `0x9f` [FMBT Rear Monitor Status](9f.md)
- `0xab` [GTF Remote Control Status](../nav/ab.md)

### Example Frames

    3B 04 47 9E 00 E6  # Monitor on
    3B 04 47 9E 01 E7  # Monitor off

## Parameters

Fixed length. One byte.

    ON  = 0x00
    OFF = 0x01

The request value is inverted compared to the state reported by `0x9f`:

    9E 00 -> 9F 01
    9E 01 -> 9F 00

## Use Cases

This is used to switch the rear monitor when GTF/FMBT are fitted.

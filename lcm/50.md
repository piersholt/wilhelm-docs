# `0x50` Check Control Status Request

Cluster `0x80` → CCM `0x30`

Requests the compact Check Control sensor status used by the low cluster.

### Related Commands

- `0x51` [Check Control Status](51.md)
- `0x52` [Check Control Message Relay](52.md)
- `0x1a` [Check Control Message](1a.md)

#### Example

    80 03 30 50 E3

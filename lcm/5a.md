# `0x5a` Cluster Indicators Request

IKE `0x80` → LM `0xd0`

Request cluster indicator status.

### Related

- `0x5b` [Cluster Indicators](5b.md)

### Example Frames

    3B 03 D0 5A B2
    60 03 D0 5A E9

## Use Cases

It is used whenever the cluster needs the current lamp/indicator state rather than waiting for the next broadcast.

# `0x52` Check Control Message Relay

Various → CCM `0x30`

This command relays Check Control warnings from other modules into the CCM message system.

The LCM stores relay messages in four internal slots. A full relay contains two control bytes followed by a 20-character string; shorter forms update relay state without replacing the text body.

### Related Commands

- `0x1a` [Check Control Message](1a.md)
- `0x50` [Check Control Status Request](50.md)
- `0x51` [Check Control Status](51.md)

## Formats

### Control only

Fixed length. 2 bytes.

| Property  | Index | Length | Type     |
|:----------|:------|:-------|:---------|
| Control 0 | `0`   | `1`    | Bitfield |
| Control 1 | `1`   | `1`    | Bitfield |

This form contains no String field. It is used for relay-state updates without replacing the stored 20-character text body.

### Control & Text

Fixed length. 22 bytes.

| Property  | Index | Length | Type     |
|:----------|:------|:-------|:---------|
| Control 0 | `0`   | `1`    | Bitfield |
| Control 1 | `1`   | `1`    | Bitfield |
| String    | `2`   | `20`   | String   |

With physical `LEN = 0x19`, the LCM copies both control bytes and all 20 text characters into the selected relay slot.

## Control 0

    IDENTITY_KEY       = 0b1111_0000
    DISPLAY_QUALIFIER  = 0b0000_1000
    OPERATION          = 0b0000_0011

### Identity Key `0b1111_0000`

Selects the relay-message identity used when locating an existing slot.

`DISPLAY_QUALIFIER` is not part of this identity comparison.

### Display Qualifier `0b0000_1000`

Retained in the relay-slot metadata. When the relay is emitted as `0x1a`, this bit is forwarded to Display bit 3.

### Operation `0b0000_0011`

    OPERATION_REMOVE   = 0b00
    OPERATION_SET      = 0b01
    OPERATION_RESERVED = 0b10
    OPERATION_REFRESH  = 0b11

#### Remove `0b00`

Removes the matching relay slot.

#### Set `0b01`

Sets or updates the relay slot. With physical `LEN = 0x19`, both control bytes and all 20 text characters are copied into the slot.

#### Reserved `0b10`

No local action is performed by the LCM handler.

#### Refresh `0b11`

Refreshes or keeps alive the matching relay slot.

## Control 1

    ONE_SHOT_PENDING = 0b1000_0000
    ALTERNATE_CLASS  = 0b0100_0000
    ACOUSTIC_CLASS   = 0b0000_1111

### One-Shot Pending `0b1000_0000`

Consumed and cleared by the relay-output path.

### Alternate Class `0b0100_0000`

Selects the alternate relay handling class.

### Acoustic Class `0b0000_1111`

Forwarded to `0x1a` Options bits `5:2` by shifting the four-bit value left by two positions.

## String

Only present in the full form and is then exactly 20 characters long.

The LCM copies all 20 characters into the relay slot before the message is processed by the normal Check Control display/gong logic. When emitted through `0x1a`, the same 20-character body is copied into the Check Control output path.

## Relay Slots

The LCM maintains four relay slots. `IDENTITY_KEY` is used to locate an existing relay, while `DISPLAY_QUALIFIER` remains metadata and does not participate in the identity comparison.

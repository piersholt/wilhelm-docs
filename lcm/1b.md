# `0x1b` IKE Text Status

Cluster `0x80` → CCM `0x30`

Acknowledges the state of the Check Control text channel used by `0x1a` [Check Control Message](1a.md).

| Value | CCM state |
|:------|:----------|
| `0x00` | IKE text inactive / no text acknowledged |
| `0x01` | IKE text active / acknowledged |

A valid status update causes the CCM to refresh its Check Control output state.

### Example Frame

    80 04 30 1B 00 AF

# `0x5c` Instrument Backlight (58G)

LM `0xd0` → Global Broadcast `0xbf`

Reports the current instrument/backlight dimmer level.

### Related Commands

- `0x5d` [Instrument Backlight Request](5d.md)

### Example Frames

    D0 05 BF 5C FF 00 C9
    D0 05 BF 5C DB 00 ED
    D0 05 BF 5C B0 00 86
    D0 05 BF 5C 84 00 B2

## Parameters

Fixed length. Two data bytes.

    # Byte 1
    DIMMER_LEVEL

    # Byte 2
    0x00

### Dimmer Level

Unsigned 8-bit dimmer level.\
`0xff` is maximum brightness; decreasing values reduce the instrument illumination level.

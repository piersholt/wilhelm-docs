# `0x73` Immobiliser Status Request

GM `0x00` → EWS `0x44`\
CCM `0x30` → EWS `0x44`

Requests immobiliser status from EWS.

### Related Commands

- `0x74` [Immobiliser Status](74.md)

### Example Frames

    00 06 44 73 00 00 80 B1  # GM
    30 06 44 73 00 00 80 81  # CCM

## Parameters

Known requests contain three data bytes:

    00 00 80

The LCM/CCM generates this request with the payload fixed to `00 00 80`.

The meaning of the individual bytes is not known yet.

# `0x74` Immobiliser Status

EWS `0x44` → Broadcast `0xbf`

Reports the current immobiliser and key-recognition state.

### Related Commands

- `0x73` [Immobiliser Status Request](73.md)
- `0x72` [Remote Key Buttons](../gm/72.md)

### Example Frames

    44 05 BF 74 00 FF 75  # No key detected
    44 05 BF 74 01 03 88  # Immobilisation deactivated, key 3
    44 05 BF 74 04 01 8F  # Valid key detected, key 1
    44 05 BF 74 05 01 8E  # Valid key detected + immobilisation deactivated, key 1
    44 05 BF 74 05 04 8B  # Valid key detected + immobilisation deactivated, key 4

## Parameters

Fixed length. Two bytes.

    # Byte 1
    IMMOBILISATION_DEACTIVATED = 0b0000_0001
    VALID_KEY_DETECTED          = 0b0000_0100

    # Byte 2
    KEY_NUMBER

### Immobilisation Deactivated `0b0000_0001`

Set when EWS reports the immobilisation state as deactivated.

### Valid Key Detected `0b0000_0100`

Set when EWS has recognised a valid key.

### Key Number

The second byte contains the EWS key number when one is available.

Values `0x00` through `0x04` have been observed. `0xff` is used when no key number is reported.

This is the EWS transponder key number and is separate from the FZV remote-key identification used by `0x72`.


## Usage

LCM uses this to detect if a key is in the ignition.
If this is the case, it will annoy you with a warning chime and a message in the IKE.

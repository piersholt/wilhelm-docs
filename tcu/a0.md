# `0xa0` TCU Emergency-Call Status

TCU `0xca` → GT `0x3b`

Updates the BMW Assist emergency-call state used by the GT.

### Related

- `0x23` [Title Text: TCU](23.md)

### Example Frames

    CA 04 3B A0 00 55
    CA 04 3B A0 80 D5

## Parameters

At least one data byte.

Only bit 7 of the first byte is used by this GT path. The remaining bits are not defined here.

    EMERGENCY_STATE = 0b1000_0000

| Bit 7 | Meaning |
|:------|:--------|
| `0` | BMW Assist emergency-call state flag clear |
| `1` | BMW Assist emergency-call state flag set |

The two values select the corresponding emergency-call state transitions in the GT. This bit is not the general TCU presence or online state; presence is established with `0x02`.

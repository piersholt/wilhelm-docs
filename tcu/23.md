# `0x23` Title Text: TCU

TCU `0xca` → GT `0x3b`

### Related

## TCU Values

Common command: `0x23` [Title Text](../common/23.md).

| Property | Index | Length | Type   |
|:---------|:------|:-------|:-------|
| Control  | `0`   | `2`    | Bytes  |
| String   | `2`   | `0-30` | String |

The two control bytes are not used for the displayed text. The string begins at index 2 and is limited to 30 characters.

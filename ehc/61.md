# `0x61` EHC Status

EHC `0xac` → Global Broadcast `0xbf`

Reports the electronic height control status used by Check Control.

### Related Commands

- `0x1a` [Check Control Message](../lcm/1a.md)

### Example Frame

    AC 04 BF 61 01 77

## Parameters

One data byte is used by LCM.

    SELF_LEVEL_SUSPENSION_ACTIVE = 0b0000_0001


### Self-Level Suspension Active `0b0000_0001`

The normal observed EHC status is `0x01`.

When set, the self-levelling suspension is reported as active/normal.\
When clear, LCM reports an inactive self leveling suspension.

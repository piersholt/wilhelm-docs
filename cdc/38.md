# `0x38` CDC Request

Radio `0x68` → CDC `0x18` / `0x76`

Controls CD changer playback and requests the current CDC state.

### Related Commands

- `0x39` [CDC Status](39.md)
- `0x3f` [CDC ID3 Text](3f.md)

### Example Frames

    68 05 18 38 00 00 4D   # Request status
    68 05 18 38 01 00 4C   # Stop
    68 05 18 38 02 00 4F   # Pause
    68 05 18 38 03 00 4E   # Play
    68 05 18 38 06 03 48   # Select disc 3
    68 05 18 38 0A 00 47   # Next track
    68 05 18 38 0C 00 41   # ID3 on
    68 05 18 38 0C 01 40   # ID3 off

## Parameters

Fixed length. Two data bytes.

| Property | Index | Length | Type    |
|:---------|:------|:-------|:--------|
| Command  | `0`   | `1`    | Map     |
| Argument | `1`   | `1`    | Integer |

### Command

    0x00: Request Status
    0x01: Stop
    0x02: Pause
    0x03: Play
    0x04: Seek
    0x05: Track Change (alternate variant)
    0x06: Select Disc
    0x07: Scan
    0x08: Random
    0x0A: Track Change
    0x0C: ID3

### Seek `0x04`

    0x00: Backward
    0x01: Forward

### Alternate Track Change `0x05`

Some radio/CDC variants use `0x05` as an alternate track-change request.\
Compatible CDC implementations handle it as a track-change operation alongside the normal `0x0a` command.

The normal next/previous form remains `0x0a`, `0x05` is retained as a compatibility variant rather than assigning argument semantics not used by the analyzed receiver.

### Select Disc `0x06`

The argument selects disc `1` through `6`.

    68 05 18 38 06 03 48   # Disc 3

### Scan `0x07`

    0x00: Off
    0x01: On

### Random `0x08`

    0x00: Off
    0x01: On

### Track Change `0x0A`

    0x00: Next Track
    0x01: Previous Track

### ID3 `0x0C`

Enables or disables ID3 text support.

    0x00: On
    0x01: Off

When ID3 is enabled and the CDC reports extended folder/track information, the radio requests fresh metadata using `0x3f` whenever the folder or track changes.

## Use Cases

The radio expects a matching `0x39` status update after a control request. If the requested action cannot complete immediately, the CDC may first report status `0x07` and send the final state afterwards.

The same command set is used for address `0x76` when that CD device is detected instead of the normal CDC address `0x18`.

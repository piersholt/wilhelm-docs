# `0x70` MRS Status

MRS `0xa4` → Global `0xbf`

GT uses this message for the automatic emergency call path.

### Related Commands

- `0x51` [Check Control Status](../lcm/51.md)
- `0x1a` [Check Control Message](../lcm/1a.md)

### Example Frames

    A4 06 BF 70 03 00 0A 64
    A4 06 BF 70 00 00 1A 77

## Parameters

Three data bytes are used.

Bit 6 of the first byte carries the emergency-call status. LCM additionally consumes the low two bits of the third byte as the seat-belt state.

    Byte 0: EMERGENCY_CALL = 0b0100_0000
    Byte 2: SEATBELT_STATE = 0b0000_0011

### Emergency Call `0b0100_0000`

When set, the GT triggers its tel/emergency call path.

### Seatbelt State `0b0000_0011`

LCM treats the low two bits of byte 2 as one two-bit selector, not as two independent flags.

| Value | LCM result |
|:------|:---------------|
| `0` | Fasten-seatbelt request clear |
| `1` | Fasten-seatbelt request active |
| `2` | Fasten-seatbelt request clear |
| `3` | Fasten-seatbelt request clear |

With the seat-belt-switch coding path enabled, value `1` feeds `0x51` `FASTEN_SEATBELT`.\
Other values clear that input.

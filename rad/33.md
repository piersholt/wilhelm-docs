# `0x33` TMC Station Status

Radio `0x68` → GT `0x3b`

TMC station/list status.

BM54 sends this command while processing TMC requests. \
The TMC status is carried in the first data byte.

### Related Commands

- `0x3c` [TMC Station List Text](3c.md)
- `0xa7` Traffic Management Channel Request
- `0xa8` [Traffic Management Channel](a8.md)

## Parameters

At least one data byte.

    CONTROL    = 0b1000_0000
    SELECTOR   = 0b0111_0000
    LIST_STATE = 0b0000_1110
    STATE      = 0b0000_0001

### Control `0b1000_0000`

When clear, `SELECTOR` and `STATE` are updated.

When set, this selector update is skipped.

### Selector `0b0111_0000`

Three-bit TMC station/list selector.

This is the same selector used by `0x3c`.

### List State `0b0000_1110`

Three-bit TMC list state.

The value `0b111` is a special list state.

### State `0b0000_0001`

State flag associated with `SELECTOR`.

BM54 may transmit four additional TMC record bytes after this status byte.\
They are not part of this status field.

# `0x4e` Radio Source / Navigation Volume

GT `0x3b` → Radio `0x68`  
Navigation `0x7f` → Radio `0x68`  
Radio `0x68` → GT `0x3b`

### Related

- `0x4f` [Video Module Source](../vid/4f.md)

### Example Frames

```
3B 05 68 4E 01 00 19  # Set source TV
3B 05 68 4E 00 00 18  # Set source radio
7F 05 68 4E 3C 00 60  # Set source navigation, navigation volume +3
```

## Parameters

### GT → Radio

Fixed length. Two data bytes.

Byte 2 is reserved.

```
# Byte 1

SOURCE       = 0b0000_0001
```

#### Source `0b0000_0001`

```
SOURCE_TV    = 0b0001  # 0x01
SOURCE_RAD   = 0b0000  # 0x00
```

### Navigation → Radio

Fixed length. Two data bytes.

Byte 1 selects the navigation source and carries the navigation-volume value.

```
SOURCE       = 0b0000_0111
SIGN         = 0b0000_1000
MAGNITUDE    = 0b1111_0000
```

#### Source `0b0000_0111`

```
SOURCE_NAV   = 0b100   # 0x04
```

#### Sign `0b0000_1000`

```
POSITIVE = 1
NEGATIVE = 0
```

#### Magnitude `0b1111_0000`

The upper nibble contains the navigation-volume magnitude.

The radio converts `SIGN` and `MAGNITUDE` to a signed navigation-volume value when switching to the navigation audio source.

Examples:

```
0x0C  # Navigation, +0
0x1C  # Navigation, +1
0x2C  # Navigation, +2
0x3C  # Navigation, +3

0x04  # Navigation, -0
0x14  # Navigation, -1
0x24  # Navigation, -2
0x34  # Navigation, -3
```

#### Byte 2
Both the BM53 and BM54 can mix in the navigation announcements over the normal audio.
Background audio mute can be forced using this bit.

```
MUTE_BACKGROUND = 0b1000_0000
```

### Radio → GT

This direction uses two data bytes. Byte 1 contains the navigation-volume value. Byte 2 is reserved.

```
TYPE       = 0b0000_0111
SIGN       = 0b0000_1000
MAGNITUDE  = 0b1111_0000
```

#### Type `0b0000_0111`

The defined type value is `0b110`.

#### Sign `0b0000_1000`

```
POSITIVE = 1
NEGATIVE = 0
```

#### Magnitude `0b1111_0000`

Values `0` through `9` are accepted and converted to a signed value using `SIGN`.

This signed value is the navigation volume.

## Use Cases

The GT uses this command to switch the radio between the radio and TV audio sources.

The navigation computer uses the same command to select the navigation audio source and provide the navigation-volume value.

In the reverse direction the radio reports the navigation volume to the GT.

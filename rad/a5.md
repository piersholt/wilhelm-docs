# `0xa5` Body Text: Radio

Radio `0x68` → GT `0x3b`  
SDRS `0x73` → GT `0x3b`

Used for individual radio display fields.

### Related

- `0x21` [Menu Text: Radio](21.md)
- `0x23` [Title Text: Radio](23.md)
- `0x24` [Property Text: Radio](24.md)

### Example Frames

    # Refresh index fields
    68 06 3B A5 60 01 00 91

    # Radio display fields
    68 0B 3B A5 62 01 01 20 46 4D 44 20 D0
    68 0B 3B A5 62 01 02 20 50 20 33 20 DF

## Radio Values

Common format: `0xa5` [Body Text](../common/a5.md).

### Layout

Known radio layouts include:

    MENU            = 0x60
    RADIO_DISPLAY   = 0x62

`0x62` is used for the title/body fields around the radio display.
`0x60` is used with the radio menu/index display.

## Use Cases

`0x62 0x01` is commonly used to write the individual radio title fields.

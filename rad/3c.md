# `0x3c` TMC Station List Text

Radio `0x68` → GT `0x3b`

TMC station-list selector and text.

### Related Commands

- `0x33` [TMC Station Status](33.md)
- `0xa7` Traffic Management Channel Request
- `0xa8` [Traffic Management Channel](a8.md)

## Parameters

Variable length.

| Property     | Index   | Length |
|:-------------|:--------|:-------|
| Control      | `0`     | `1`    |
| Text Block 1 | `1`     | `8`    |
| Text Block 2 | `9`     | `8`    |
| Text Block 3 | `17`    | `8`    |

The text blocks are optional and contain fixed-width TMC station-list text.

### Control

    STATE     = 0b1000_0000
    SELECTOR  = 0b0000_0111

### State `0b1000_0000`

State flag associated with `SELECTOR`.

The selector/state pair corresponds to the same TMC list state used by `0x33`.

### Selector `0b0000_0111`

Three-bit TMC station/list selector.

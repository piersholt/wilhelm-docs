# `0x21` Menu Text: Radio

Radio `0x68` → GT `0x3b`  
SDRS `0x73` → GT `0x3b`

Radio and SDRS use this format for station and menu lists.

## Radio Values

Common format: `0x21` [Menu Text](../common/21.md).

### Layout

    MENU = 0x60

### Function

The normal radio index uses `0x00`.

### Index

Split-screen station fields use indexes `0x40` through `0x49`, with some fields only applicable in full-screen mode.

## Use Cases

This is the legacy radio station/menu list used before the NG station list `0xd4`.

Radio and SDRS use the same menu-text format. Writing `0x21` also replaces the currently displayed NG station list.

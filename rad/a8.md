# `0xa8` Traffic Management Channel

Radio `0x68` → GT `0x3b`

BPF TMC state.


### Related Commands

- `0x33` [TMC Station Status](33.md)
- `0x3c` [TMC Station List Text](3c.md)
- `0xa7` Traffic Management Channel Request

## Parameters

Two data bytes.

### Byte 0

    MODE       = 0b1111_0000
    MARKER     = 0b0000_1111

`MARKER` is `0x0f`.

Three BPF TMC modes are defined:

    MODE_1 = 0x10
    MODE_2 = 0x20
    MODE_3 = 0x30


Mode 1 is associated with the `0x1f` `0xa7` request path. Modes 2 and 3 are associated with the `0x3f` request path.

### Byte 1

BPF TMC state.

Defined wire values are `0x00` through `0x04`.

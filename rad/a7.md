# `0xa7` Traffic Management Channel Request

Navigation `0x7f` → Radio `0x68`

Requests and configures the radio-side RDS/TMC receiver. The analyzed BM54 dispatches this command by the high nibble of the first data byte and implements the `0x2x` and `0x3x` request families.

### Related Commands

- `0xa8` [Traffic Management Channel Response](a8.md)

## Request Selectors

The first data byte is the request selector.

| Selector | Function |
|:--|:--|
| `0x20` | Initialize/reset TMC response state |
| `0x31` | Enable/disable TMC |
| `0x32` | Query filtered service table A |
| `0x33` | Query filtered service table B |
| `0x34` | Configure raw receive inputs |
| `0x35` | Reserved/legacy path |
| `0x36` | Receiver/status query |
| `0x37` | Current service/status query |
| `0x38` | Read receive-input configuration |
| `0x3a` | Scan/update control |
| `0x3f` | TMC availability/current-service query |

## TMC Enable `0x31`

```text
31 00   # disable
31 xx   # enable when xx != 0
```

The radio resets TMC receive state when disabling and initializes the service/receiver state when enabling.

## Receive Inputs `0x34`

```text
34 MODE
```

```text
TMC_TRAFFIC_GROUP   = 0b0000_0001
RDS_CLOCK_TIME      = 0b0000_0010
```

The mask controls two independent raw RDS inputs in the analyzed BM54.

- Bit 0 enables processing of the configured TMC traffic group.
- Bit 1 enables RDS group 4A Clock-Time/Date processing.

`0x38` reads this mask back.

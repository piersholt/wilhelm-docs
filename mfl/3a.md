# `0x3A` MFL Recirculating Air Control

MFL `0x50` → IHKA `0x5b`

### Related Commands

- `0x3b` [MFL Buttons](3b.md)

### Examples

```
50 04 5B 3A 00 35
50 04 5B 3A 01 34
```

## Parameters

Fixed length. One byte bit field.

```
BUTTON = 0b0000_0001
```

### Button `0b0000_0001`

```
BUTTON_RELEASE = 0b0000_0000   # 0x00
BUTTON_PRESS   = 0b0000_0001   # 0x01
```

## Use Cases

### Recirculating Air Control

The MFL recirculation button sends its state to IHKA `0x5b`.

```
50 04 5B 3A 01 34   # Press
50 04 5B 3A 00 35   # Release
```

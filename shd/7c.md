# `0x7c` Sunroof Status

Sunroof Module `0x08` → Global Broadcast `0xbf`

Reports sliding/tilting sunroof status.

The SHD tracks the roof position and operating state internally. The General Module separately reports a coarse sunroof-open state in `0x7a` Door/Lid Status.

# `0x7d` Sunroof Control

General Module `0x00` → Sunroof Module `0x08`\
General Module `0x00` → Global Broadcast `0xbf`

Carries central-locking and convenience-operation state from the General Module to the sliding/tilting sunroof system.

### Related Commands
- `0x72` [Remote Key Buttons & Status](../gm/72.md)
- `0x7a` [Door/Lid Status](../gm/7a.md)

### Example Frames

    00 05 08 7D 00 00 70  # Locked; comfort inactive
    00 05 08 7D 00 10 60  # Unlocked; comfort inactive
    00 05 08 7D 00 30 40  # Unlocked; comfort opening active
    00 05 08 7D 00 50 20  # Unlocked; comfort inactive; close direction retained
    00 05 08 7D 00 70 00  # Unlocked; comfort closing active

    00 05 BF 7D 00 20 E7  # Locked; comfort opening active, broadcast variant
    00 05 BF 7D 00 60 A7  # Locked; comfort closing active, broadcast variant

## Parameters

Fixed length. Two bytes.

    Byte 1
    0x00

    Byte 2
    LOCK_STATE         = 0b0001_0000
    COMFORT_ACTIVE     = 0b0010_0000
    COMFORT_CLOSE      = 0b0100_0000

### Lock State `0b0001_0000`

    0  LOCKED
    1  UNLOCKED

### Comfort Active `0b0010_0000`

Set while a convenience opening/closing operation is active.

### Comfort Direction `0b0100_0000`

Direction flag for the convenience operation:

    0  COMFORT_OPEN
    1  COMFORT_CLOSE


The direction bit is independent of `COMFORT_ACTIVE`. Therefore values such as `0x40` and `0x50` are not a third sunroof action; they indicate that comfort operation is currently inactive while the close-direction state is set.

The active operation forms are:

    0x20 / 0x30  comfort opening active
    0x60 / 0x70  comfort closing active

## Use Cases

### Convenience Opening/Closing

The General Module coordinates convenience operation from the mechanical key and remote control. It forwards the active state and direction to the SHD so that the sunroof can operate together with the power windows.
